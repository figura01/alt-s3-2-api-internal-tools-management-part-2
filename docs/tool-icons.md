# Tool icons

The shared `ToolIcon` component is used by the catalogue, recent tools and detail pages.

- An explicit HTTPS or local icon URL takes priority. Failed images fall back to the bundled identity, then a pictogram or initials.
- Exact tool names select bundled identities; only the five fictional demo names also accept the staging `Demo ` prefix.
- Figma and GitHub images are served locally, unmodified and with preserved proportions. Total original file size: 7,661 bytes.
- Notion, ChatGPT and Codex use generic Lucide pictograms, not their official logos. The five fictional tools also use Lucide pictograms. Lucide is already installed (ISC license); no icon library is added.
- Icons are decorative beside the tool name. Fixed dimensions prevent layout shifts; both themes use readable colours. Remote icons send no referrer.
